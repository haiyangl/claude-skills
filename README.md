# Haiyang's Claude Code Skills

A collection of [Claude Code](https://www.anthropic.com/claude-code) skills.

Each skill lives in its own directory with a `SKILL.md` (the skill itself) and its own `README.md` (what it does and how to use it). To install one, drop its directory where Claude Code discovers skills, e.g. `~/.claude/skills/<name>/`.

## Skills

| Skill | Description |
|-------|-------------|
| [launch-session](launch-session/) | Hand a drafted prompt to a fresh, addressable `claude` session — no copy-paste, with two-way messaging between launcher and child. |
